# Amp Social Wallet 🚀

Web3 social trading app: Crypto chats, group tips, token swaps—like Twitter + Uniswap for degens. Prototype ready in HTML/JS; scaling to Flutter + Base/Eth chains.

## Why Amp?
- Post trades (e.g., $DOGINME pumps), join newbie groups.
- Wallet connect: MetaMask/Base, sim buys, $AMP rewards.
- Ties to my forks: ERC20 tokens ([doginmeERC20](https://github.com/Ampie123567/doginmeERC20)), payments ([coinbase-superpay](https://github.com/Ampie123567/coinbase-superpay)), AI agents ([world_ai_protocol](https://github.com/Ampie123567/world_ai_protocol)).
- Monetize: Freemium subs, token airdrops, affiliate swaps.

## Get It Running (Prototype)
1. Download [amp-wallet.html](prototype/amp-wallet.html).
2. Open in browser—connect "wallet", join groups, fake-trade $AMP.

## Stack
- Frontend: HTML/JS → Flutter mobile.
- Web3: ethers.js for Eth/Base.
- Backend: Firebase chats.
